# Pazham Panam - Premium Banana Stock Market

**"Trade Pazham. Make Panam."**

A sophisticated, minimalist fintech-style application that transforms Kerala's finest banana varieties into tradable financial assets. Built for college hackathons with a professional aesthetic that initially appears to be a legitimate stock trading platform.

## 🎯 Concept

Pazham Panam is a fictional banana stock market where users can:
- Buy and sell different Kerala banana varieties
- Track real-time price movements
- Manage their banana portfolio 
- View market analytics and rankings
- Monitor transaction history

The core humor lies in treating ordinary Kerala bananas as serious financial instruments while maintaining the polished look of a premium trading platform.

## 🚀 Quick Start

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd pazham-panam
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```
   
   The application will be available at `http://localhost:3000`

### Alternative Setup

For a simple setup without Node.js:
1. Open `index.html` directly in your browser
2. Use any local server (Python, Live Server extension, etc.)

## 🎮 Usage Guide

### Getting Started
1. **Landing Page**: Click "Enter Market" to access the trading platform
2. **Market View**: Browse available banana varieties with live prices
3. **Trading**: Click any banana to view details and initiate trades
4. **Portfolio**: Track your holdings and performance metrics
5. **Analytics**: Explore market rankings and transaction history

### Navigation
- **Market**: Main trading dashboard with banana listings
- **Portfolio**: Personal holdings and performance tracking
- **Rankings**: Market analytics and top performers
- **History**: Complete transaction log with filtering

### Trading Process
1. Select a banana from the market dashboard
2. Choose Buy or Sell in the trading modal
3. Set quantity using +/- controls or direct input
4. Review total value and available balance
5. Confirm trade execution
